## Code authorship and provenance

`RatiometricCaImagingSingleTimepoint.m` was written by Nicole S. Sarna for single-timepoint Fluo-4/Fura-Red ratiometric calcium analysis and adapted for cancer cell analysis. It is hosted here with her permission to consolidate the materials supporting Ismael Ortiz’s dissertation. The original header comment block is preserved.

Original source: [https://github.com/nicolesarna/ratiometric-ca-imaging](https://github.com/nicolesarna/ratiometric-ca-imaging)

Original software archive: [https://doi.org/10.5281/zenodo.24380711](https://doi.org/10.5281/zenodo.24380711)

## Methodological reference

The segmentation and background-correction approach was adapted from Sarna et al., *iScience* **27**, 109999 (2024), and modified by Nicole S. Sarna for two-channel Fluo-4/Fura-Red ratiometric analysis.

[https://doi.org/10.1016/j.isci.2024.109999](https://doi.org/10.1016/j.isci.2024.109999)

## Segmentation settings and quality control

The thresholds and watershed settings were tuned using one representative image from this study. Users should inspect the quality-control overlays and reassess these settings when applying the program to images acquired under different conditions.
